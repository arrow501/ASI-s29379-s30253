ignorowana przez Git. Klucza W&B nie umieszczamy w parametrach Kedro: używamy
`wandb login` albo zmiennej `WANDB_API_KEY`. Konfiguracja i tymczasowy dostęp:
[notatka W&B](../../docs/notes/sprint-3-wandb.md).
